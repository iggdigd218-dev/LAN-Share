# LAN Share — تطبيق ويندوز + تطبيق أندرويد

مشاركة ملفات الكمبيوتر مع الهاتف عبر **شبكة LAN الخاصة بالمحل** (نفس الراوتر / Wi‑Fi).  
تصفح المجلدات، تشغيل الأغاني والفيديو، ونسخ الملفات إلى الهاتف.

---

## 1) تطبيق ويندوز (الكمبيوتر)

1. ثبّت [Python 3](https://www.python.org/downloads/) وفعّل خيار **Add python.exe to PATH**.
2. انسخ مجلد `lan-share` إلى الكمبيوتر.
3. شغّل الملف:

```
windows\تشغيل.bat
```

أو من موجه الأوامر:

```bat
cd lan-share
python -m pip install fastapi uvicorn python-multipart qrcode[pil] aiofiles pillow
python windows\app.py
```

سيظهر:

- عنوان مثل `http://192.168.1.15:8080`
- رمز **PIN** من 6 أرقام
- رمز QR
- زر **إضافة مجلد للمشاركة**

اترك النافذة مفتوحة طوال الاستخدام.

---

## 2) تطبيق أندرويد (الهاتف)

المشروع جاهز في مجلد `android/` لفتحه من **Android Studio**:

1. ثبّت [Android Studio](https://developer.android.com/studio).
2. File → Open → اختر مجلد `lan-share/android`.
3. انتظر مزامنة Gradle.
4. وصّل هاتفاً أو محاكياً ثم Run (▶).

بعد التثبيت على الهاتف:

1. تأكد أن الهاتف والكمبيوتر على **نفس شبكة المحل**.
2. اضغط **بحث تلقائي في الشبكة**.
3. اختر الكمبيوتر، أدخل **PIN** الظاهر في برنامج ويندوز.
4. تصفح الملفات:
   - مجلد → فتح
   - أغنية / فيديو → تشغيل على الهاتف
   - **نسخ** → تنزيل الملف إلى مجلد التنزيلات في الهاتف

يمكن أيضاً إدخال العنوان يدوياً مثل: `http://192.168.1.15:8080`

---

## ملاحظات الشبكة

- لا يحتاج إنترنت خارجي.
- الجدار الناري في ويندوز قد يسأل عن السماح لـ Python — اختر **سماح** للشبكات الخاصة.
- إن فشل البحث التلقائي، اكتب عنوان IP يدوياً (من نافذة برنامج الكمبيوتر).
- رمز PIN يتغير في كل تشغيل لحماية الشبكة المحلية.
